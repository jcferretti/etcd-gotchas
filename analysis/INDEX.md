# Analysis index

One row per analysis file in this directory. File conventions are in
`../AGENTS.md` §5.

## Author suffixes

Each file is written by one agent tool; the filename suffix names it.

| Suffix | Tool | Typical model |
|---|---|---|
| `-claude.md` | Claude Code (Anthropic) | Opus 5.5, xhigh |
| `-codex.md` | Codex (OpenAI) | GPT-Astra, xhigh |
| `-agy.md` | Antigravity CLI (Google) | Gemini 4 Argon |

Files sharing a prefix (`chubby-perspectives-`, `etcd-issues-and-mitigations-`,
`leases-`, `nuraft-rocksdb-rewrite-`, `storage-`, `wal-replacement-`,
`watchers-`) are separate analyses of the same question
by different tools. Some were later revised using ideas from their peers;
each such file says so.

On 2026-11-06 Codex and Antigravity reviewed all their `-codex` and `-agy`
files and added or revised claim-level confidence tags; Antigravity then
removed the tags on settled facts from its files (`../log.md`).

On 2026-11-08 and 2026-11-09 all three tools extended their `leases-`,
`watchers-` and `etcd-issues-and-mitigations-` files with the two Jepsen
reports ([etcd 3.4.3](https://jepsen.io/analyses/etcd-3.4.3), 2020;
[jetcd 0.8.2](https://jepsen.io/analyses/jetcd-0.8.2), 2024) and the state
of their fixes at the pinned releases. The three `etcd-issues-and-mitigations-`
briefs also gained a review of maintenance capacity and governance
(`../log.md`).

Exceptions: the `*-critique-claude.md` files are not further analyses.
- `leases-critique-claude.md` records which claims from the peer lease
  analyses Claude rejected or qualified, and why.
- `chubby-perspectives-critique-claude.md` reviews one peer file,
  `chubby-perspectives-agy.md`. It was written for Antigravity to use when
  correcting that file, and is pinned to the version it reviewed.
