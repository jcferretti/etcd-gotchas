# The Chubby paper (not included in this public copy)

This file held a Markdown conversion of the full text of Mike Burrows,
*The Chubby lock service for loosely-coupled distributed systems*, OSDI 2006.
It was removed from this public copy because the paper's copyright is not ours
and no license allowing redistribution could be found.

Read the paper from its official sources:

- [USENIX PDF](https://www.usenix.org/legacy/event/osdi06/tech/full_papers/burrows/burrows.pdf)
- [Google Research](https://research.google/pubs/the-chubby-lock-service-for-loosely-coupled-distributed-systems/)

Citations such as `doc/chubby-osdi06.md:263`, and a bare `:263` after a
reference to the paper, give line numbers in the removed conversion, so they do
not match this file. Use the section cited with them (for example §2.8), which
matches the PDF. Page numbers count PDF pages from 1; the USENIX copy prints
335–350 on those pages (p. 7 is printed 341).
